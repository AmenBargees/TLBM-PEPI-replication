# TLBM multiphase code and PEPI replication inputs

Multiphase Thermal Lattice Boltzmann code (TLBM_fast v2.6 family, Peter Mora;
melt-extraction and diagnostics updates 2026-11, Amen Bargees) with the input
files to replicate the runs of the PEPI paper
"A multiphase Thermal Lattice Boltzmann Method for immiscible phases and
miscible components" (Mora, Bargees et al., submitted).

(free for research, education and non-profit use; notice must be retained).

Build: gcc -c -w -fPIC -march=native -Ofast TLBM_fast.c -lm -o TLBM_fast.o
       gcc -shared TLBM_fast.o -lm -o TLBM_fast.so
Run:   mpirun -np <N> python3 TLBM_fast.py <project> <run>
