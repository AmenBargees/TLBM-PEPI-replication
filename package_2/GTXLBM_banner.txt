# GTXLBM can model both solid-state and liquid-state fluid dynamic systems
# from laminar flow to turbulent convection into the ultimate turbulent regime.
# It uses the D2Q9 or D3Q19 LBM lattice structure and can be run using single
# relaxation time (SRT), two relaxation time (TRT) or multiple relaxation time (MRT).
# The main program is written in Python with the ability to call a highly optimized
# C kernel with high performance and scaling on HPC CPU clusters to at least 300 K
# cores on CPU clusters.
#===============================================================================
# Release 2.95 summary
#-------------------------------------------------------------------------------
# Author: Peter Mora
#-------------------------------------------------------------------------------
# Capabilities
#-------------------------------------------------------------------------------
# Single phase fluid dynamics in 2D & 3D Cartesian models and in 2D annulus models,
# on multi-core workstations or HPC CPU clusters, ability to model nonlinear
# rheology, temperature-dependent viscosity, wide range of Rayleigh and Prandtl
# numbers, with options for free-slip or no-slip boundary conditions on the upper &
# lower boundaries, and free-slip, no-slip or periodic BCs on the side boundaries.
#===============================================================================
# Capabilities of future releases based on prototype software already developed
#===============================================================================
# (1) 3D spherical model capability,
# (2) Multiphase immiscible and miscible capability,
# (3) GPU capability,
# (4) Pressure and temperature dependent viscosity capability for magma oceans,
# (5) pressure and velocity side boundary conditions.
#-------------------------------------------------------------------------------
# Couthors of prototype software
#-------------------------------------------------------------------------------
# Gabriele Morra: Python optimization & scaling, GPU capability, P-T dependent viscosity
#     for magma ocean dynamics and turbulent magma ocean chemical equilibriation research.
#
# Leila Honarbakhsh & Gabriele Morra: Immiscilbe multiphase TLBM to model iron clouds
#     - generated by iron-rich impactors - decending in a turbulent magma ocean for
#     planetary accretion and chemical differentiation research.
#
# Amen Bargees: combined immiscible & miscible multiphase capability, and partial melting
#     capability for peridotite to TTG's and basalt for continent formation research.

# GTXLBM runs on Linix systems. The install script provides an easy one-step
# installation process of GTXLBM. Other software requirements are standard on
# Linux systems such as the GNU compiler, plus Python & Python libraries.
# Python and any missing Python libraries can be installed with "apt".
#===============================================================================
# Documentation and help
#===============================================================================
# The README file explains how to run GTXLBM and its directory structure which is
# organized into projects and runs of projects. It also explains scripts which
# an easy means to run and/or generate plot files from data files for one or more
# run(s) and projects(s), to display plots for a run, to move between directories,
# and to create tar and backup files. An "examples" project provides input files
# for a range of geodynamics problems: (1) Archean geodynamics (archean.in),
# (2) mantle connvection in a full annulus (mantle.in), (3) mantle convection in
# an annulus spanning 120 degrees (mantle_annulus.in), (4) mantle convection in
# a 3D Cartesian model (mantle3D.in), and (5) turbulent magma ocean convection at
# a high Rayleigh number and a low Prandtl numbber (hadean.in).
#-------------------------------------------------------------------------------
# The papers directory contains research papers on by the author and collaborators
# The key paper is Mora et al. (2026). It describes TLBM theory, how dimensional
# time relates to dimensionless LBM time, how dimensional (physical) properties
# relate to dimensionless LBM properties. It includes examples (Archean geodynamics,
# 2D & 3D mantle convection, turbulent magma), throughput and scaling performance
# to 300 K cores, and Appendices showing Re scaling with Ra, Pr scaling with aspect
# ratio, lattice size requirements to model at ultra-high Rayleigh numbers, even into
# the ultimate turbulent regime (Ra >~ 10^14), and a sinking block multiphase test.
